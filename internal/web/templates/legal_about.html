关于

PlainMote 用于在线分享配置、日志和其他文件：可为每个人或每台机器分别创建链接，每条链接可独立设置有效期与使用次数、单独撤销，每次访问均有记录。

主要功能

  • 独立的分享链接：同一资源可创建多条链接，分别设置有效期和使用次数，撤销其中一条不影响其他链接。
  • 免登录访问：接收者打开链接即可获取内容，无需注册或登录。
  • 访问记录：每次通过链接的访问均记录时间、来源 IP 和客户端信息，仅资源所有者可见。
  • 历史版本：修改资源内容后，被替换的版本会保留一段时间，可查看、对比和恢复；访问记录注明每次获取的是哪个版本。
  • 远程资源：可仅保存公网地址，每次访问时由服务器实时从源站获取内容。
    • {{if .Legal.Anonymous}}
  • 临时分享：无需登录，在首页粘贴文本或上传文件即可生成有效期最长 {{legalDuration true .Legal.AnonymousTTL}}的链接。
  • 端到端加密（可选）：登录用户设置主密码后，可为资源和临时分享开启端到端加密，内容在浏览器中加密，本服务仅保存密文；密钥随链接传递的，本服务无法读取其内容，以 4 位口令代替密钥的，保护程度较低。
    • {{end}}

隐私与安全

本服务不展示广告，不使用分析脚本或第三方跟踪工具。分享链接即为访问凭证，为防止链接经搜索引擎收录而泄露，分享链接及账号相关页面均禁止搜索引擎收录。本服务处理的信息详见《隐私政策》。

About

PlainMote shares configs, logs and other files online: a separate link for each person or machine, each with its own expiry and use limit, revocable on its own, with every access recorded.

Features

  • Independent share links: a single resource can have multiple links, each with its own validity period and use limit. Revoking one link does not affect the others.
  • Access without an account: recipients retrieve content simply by opening the link, with no registration or sign-in required.
  • Access records: each access through a link records the time, source IP address and client information, visible only to the resource owner.
  • Version history: when the content of a resource changes, the version it replaces is kept for a period and can be viewed, compared and restored; access records state which version each access received.
  • Remote resources: a resource can consist of a public URL only, with the content fetched live from the origin server by the Service on each access.
    • {{if .Legal.Anonymous}}
  • Quick shares: paste text or upload a file on the home page, without signing in, to generate a link valid for up to {{legalDuration false .Legal.AnonymousTTL}}.
  • End-to-end encryption (optional): signed-in users who set a master password can turn it on for resources and quick shares; content is encrypted in the browser and the Service stores only the ciphertext; where the key travels in the link, the Service cannot read the content, and a four-character code used in place of the key offers weaker protection.
    • {{end}}

Privacy and security

The Service displays no advertising and uses no analytics scripts or third-party tracking tools. Because a share link serves as the access credential, share links and account pages are excluded from search engine indexing to prevent links from being exposed. Details of the information the Service processes are set out in the Privacy Policy.
